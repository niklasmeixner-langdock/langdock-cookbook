# Agent API Recipes

Recipes for the [Langdock Agent API](https://docs.langdock.com) — kept separate
from `mcp/` and `a2a/` because this is Langdock's own chat API, not a protocol
host integration.

| Recipe | What it shows |
|---|---|
| [`embed-iframe/`](embed-iframe/) | Host a chat widget in front of the Agent API and iframe it on SharePoint / intranet. The browser never sees the API key. |
